# CapstoneDesign - Dongguk University



## 🪐 프로젝트 제목 : 자율 주행형 선체 외판 용접부 전처리 로봇 자동 경로 생성 기술 연구




## 🤷 팀원

  * 이정민
  * 김준호
  * 나영진
  * 김서윤

| 시연    | 중간 시연 | 이정민, 김준호, 나영진, 김서윤 |
| 경로 생성 알고리즘 개발    | 전처리가 필요한 면을 정확하고 빠르게 경유할 수 있는 알고리즘 개발 | 나영진, 김서윤 |
| 경로 생성 알고리즘 고도화    | 경로 생성 알고리즘의 정확도 향상 | 이정민, 김서윤, 나영진 |

## 🎯 목적 

 > 최근 조선업에는 인력이 부족합니다.
> 
 > 따라서 선박 표면의 전처리 작업 중 경로를 설정해주는 작업을 자동화해야 할 필요가 있습니다.
>
 > 이에 한화오션과 연계하여 현업에 적용될만한 캐리지로봇(전처리로봇)의 자율주행 기술을 개발했습니다.



## 📚 기능

  * 표면 실시간 탐지
     * 캐리지로봇이 선박의 표면에서 전처리가 필요한 면을 실시간으로 탐지할 수 있습니다.
     
  * 클래스 분류
     * 전처리가 필요한 면에는 크게 용접선과 전처리 되지 않은 면으로 구분할 수 있습니다.
     * 캐리지로봇은 전처리가 필요한 면에서 용접선과 전처리가 되지 않은 면을 구별할 수 있습니다.
     
  * 자율주행 경로 생성
     * 캐리지로봇은 탐지한 전처리가 필요한 면을 분석해 최적의 경로를 생성합니다.
     * 경로를 따라 자율주행할 수 있습니다.
